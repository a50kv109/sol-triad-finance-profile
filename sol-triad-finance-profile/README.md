# SOL-Triad Finance Profile (`sol-triad-finance-profile`)

**Репозиторий специализированного интеграционного профиля и адаптера для финансовых сценариев поверх универсального ядра `sol-triad-core`.**

---

## 1. Позиционирование и архитектурные границы

Данный репозиторий **не является** самостоятельным платёжным ядром, банковским шлюзом или клиринговой системой. Он представляет собой **интеграционный профиль и адаптер (`FinanceFxAdapter`)**, демонстрирующий применение математически строгого ядра **`sol-triad-core`** к задаче верификации валютно-обменных и переводных операций.

### Разделение ответственности:
```
[ Financial Product / Agent ] ──► [ FinanceFxAdapter ] ──► [ SOL-Triad Core ] ──► [ Verdict ] ──► [ External Execution Controller ]
   (Заявка / TaskRequest)         (Трансляция в S, C, D)    (Детерминированная проверка)    (PASS/REVIEW/FAIL)   (Принимает решение об отправке платежа)
```

1. **`sol-triad-core` (Универсальное ядро):** Чистый математический верификатор триады ($S, C, D$). Гарантирует детерминизм, проверку полномочий, симуляцию состояния и отсутствие прав на выполнение (`execution_permitted = Strict False`).
2. **Финансовый профиль (`sol-triad-finance-profile`):** Описывает сущности финансовой транзакции (`TaskRequest`, `HostPolicy`, `FxPaymentResult`) и правила их перевода в канонические примитивы ядра.
3. **`FinanceFxAdapter`:** Преобразует финансовую заявку в канонический запрос, проверяет соответствие домена потерь политики хоста и запрашивает верификацию у ядра.
4. **Внешний Исполнительный Контроллер (Host Execution Controller):** Внешний компонент хоста, который получает отчёт ядра и принимает финальное решение о выполнении или блокировке платежа. **Финансовый профиль не осуществляет реальных переводов средств.**

---

## 2. Статус реализации (Audit Status)

- **Реализовано (Implemented):** Модели `TaskRequest`, `HostPolicy`, `FxPaymentResult` и логика `FinanceFxAdapter` в `adapter.py`.
- **Проверено (Verified):** Набор модульных и интеграционных тестов в `sol-triad-core/tests/adapters/test_finance_fx_adapter.py` (успешно пройдено 100% тестов).
- **Симулируется (Simulated):** Проверка балансов, конверсия валют по курсам и проверка котировок в реестре.
- **Не реализовано (Not Implemented):** Реальная банковская интеграция (SWIFT, SEPA, API банков), криптографический клиринг и производственная обработка транзакций.

---

## 3. Быстрый старт и запуск демонстрационного стенда

### Требования
- Python 3.9+
- Доступ к репозиторию `sol-triad-core` (в качестве библиотеки/модуля).

### Запуск тестов финансового адаптера
```bash
python3 sol-triad-core/tests/run_all_tests.py
```

### Запуск финансового демонстрационного сценария
```bash
python3 sol-triad-core/examples/fx_payment_pipeline_demo.py
```
